# 🌟 Memory Journal Web App

A clean and emotional memory journaling app built with **HTML, CSS, and JavaScript**. It allows users to preserve memories with a title, description, date, and mood — capturing not just events, but emotions.

---

## 📸 Features

- 📝 Add meaningful memories
- 📅 Select the date of the memory
- 😄 Choose an emoji to match your mood
- 🧹 Clean, responsive, and minimal design
- 🔄 Real-time updates using DOM manipulation

---

## 🎯 Goal

This project was created to help preserve the feeling behind each moment. It’s a lightweight, emotion-focused journaling space to hold onto the moments that matter.

---

## 💡 Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling and custom fonts  
- **JavaScript (Vanilla)** – Interactivity and DOM manipulation
